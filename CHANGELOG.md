# Changelog

All notable changes to this reproducibility repository are documented here.

## 1.2.1 — 2026-08-31

Portable reproducibility release for the current manuscript.

- Aligns runtime configuration, documented environment variables and
  command-line smoke testing.
- Pins the frozen Python environment and adds a clean-room verification guide.
- Adds a public-archive policy and release checklist for GitHub/Zenodo.
- Corrects documentation of eICU hospital-to-unique-patient bootstrap clusters.
- Removes legacy aggregate hospital-ranking diagnostics that are not used by
  the current manuscript.
- Removes the stale v1.2.0 DOI from v1.2.1 citation metadata pending a
  version-specific Zenodo record.
- Retains the frozen aggregate results; no primary numerical estimate changes.
